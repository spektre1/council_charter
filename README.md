# VRChat Safety Council Charter Drafting space

This is a set of documents related to establishing a safety council with drafted guidance and processes for intergroup communication of safety issues with the goal of solving the existing problems that have so far prevented this sort of organization. It aims to solve specific problems, such as conflicts of interest, and regulatory capture by social dominant groups.

This is a series of living documents. The initial set are drafted by Buzzkill and Dani makes, authors will be updated as this proceeds.
